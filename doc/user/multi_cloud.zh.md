# 多网盘存储

VeneraPlus 可通过内置 OpenList 内核连接百度网盘、夸克网盘、115 网盘、123 云盘、OneDrive 和 Google Drive；WebDAV 仍可作为一个独立账号使用。

内置内核由 Venera-OpenList-Core 独立构建并随应用打包；应用只使用已发布的固定内核版本，不会在设备上下载或运行 OpenList 服务。

在“存储与同步”中先添加账号。OpenList 账号使用 [OpenList Token 页面](https://api.oplist.org/) 获取的授权数据手动导入；应用不会把 OpenList HTTP 服务暴露到网络。

获取授权时选择“使用 OpenList 提供的参数”。百度网盘、123 云盘（OAuth 授权）、OneDrive 和 Google Drive 只需填写刷新令牌；在线 API 地址等参数由内置内核提供，无需填写客户端 ID 和密钥。115 按官方配置填写访问令牌与刷新令牌。夸克当前驱动还需填写 AppID、SignKey，官方未提供可内置的默认值。也可展开“导入 Token JSON 或回调”批量填充授权字段，导入后仍可直接修改 Token。

“来源与服务 → 漫画库”可为每个漫画库选择一个账号和一个或多个识别目录。目录会合并展示；相同完整远端路径的漫画只显示一次，不同目录下的同名漫画会分别显示。同步数据和漫画备份各自只能选择一个账号和一个目录。

漫画库账号授权会随应用数据快照同步。恢复快照时，本机仍有效的授权优先保留；数据同步目标始终保留在本机。漫画备份配置是否同步由“同步备份配置”选项决定。

本次改动的原生 OpenList 编译、各平台加载和六种网盘实机验证尚未在本地运行；它们安排在 CI 和专用测试目录完成。

macOS 应用仍支持 macOS 12；受 Go 1.27 运行时限制，OpenList 六种网盘仅在 macOS 13 及以上可用。在 macOS 12 上，WebDAV 和本地功能仍可使用。
