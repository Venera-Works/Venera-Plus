# 应用数据同步

English: [data_sync.en.md](data_sync.en.md)

入口：**设置 → 存储与同步 → 数据同步**。填写 WebDAV 目录 URL、用户名和密码；目录大小写必须与服务端一致。未配置时，顶栏同步按钮会打开此页面；配置后顶栏可直接选择上传或下载。

同步使用 WebDAV 根目录中的完整快照，文件名为 `<day>-<dataVersion>.venera`。每次上传替换当天较早的快照，并最多保留十份。快照包含设置、收藏、阅读历史、Cookie 和漫画源文件，不包含本地漫画图片、下载归档或远端漫画库内容。下载只在远端版本较新时覆盖恢复本地数据，不进行记录合并或冲突处理。

## 同步模式

| 模式 | 行为 |
|---|---|
| 手动 | 只通过顶栏或 CLI 的上传、下载操作传输。 |
| 实时 | 本地修改后上传；启动和恢复前台检查下载，恢复检查至少间隔 10 分钟。 |
| 定时 | 每隔 5、15、30、60、180 或 360 分钟自动同步，默认 30 分钟。 |

自动同步有本地待上传修改时优先上传；没有待上传修改时才检查并下载较新的远端快照。上传失败会保留待上传标记，供下一次自动同步重试。定时器仅在应用进程运行时有效，应用关闭后不会唤醒系统。

选择实时或定时模式时，需要选择首次上传或下载。首次传输成功后才保存新配置；失败会恢复原有连接、模式、间隔和排除字段。手动模式直接保存配置。升级自旧协议时会将原有同步时机映射为手动、实时或定时模式，并优先上传本机当前数据；旧协议状态与旧云端目录不会读取、转换或删除。

## 同步边界

WebDAV 同步连接、同步模式、间隔、待上传状态、本地路径及 Bangumi 的本地重试队列保留在本机。`disableSyncFields` 中列出的设置不会写入快照。漫画库配置始终参与设置同步，包含其连接信息；请只在可信的 WebDAV 服务上使用。

本地导入和云端下载均按完整 `.venera` 快照恢复，并在失败时还原已替换的文件。恢复后会重新加载数据库、漫画源和相关运行时服务；仅本地手动导入会作为新的本地修改进入后续同步，云端下载不会反向触发上传。旧快照不含主页收藏夹绑定时，会解除本机旧绑定。
