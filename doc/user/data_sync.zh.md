# 应用数据同步

English: [data_sync.en.md](data_sync.en.md)

入口：**设置 → 存储与同步 → 数据同步**（未配置时亦可直接点击顶栏同步按钮引导配置）。填写 WebDAV 目录 URL、用户名和密码；URL 中的目录大小写应与服务端一致。可先使用“测试连接”检查目录访问权限。

应用数据包含设置、收藏、历史、Cookie 和漫画源文件等，不包含本地漫画图片。漫画归档备份和 WebDAV 在线漫画库分别配置。

## 同步方向与时机

主页同步图标执行已选方向，实际排队工作期间旋转；未配置 WebDAV 时打开设置。方向与时机相互独立：

| 方向 | 行为 |
|---|---|
| 双向（默认） | 对照上次可信远端快照检查双方变更；仅本地变化时上传，仅远端变化时下载，双方变化或基线未知时要求明确选择快照。空服务器由本地数据初始化。 |
| 仅上传 | 发布本地快照，绝不下载。 |
| 仅下载 | 应用最新远端快照，绝不上传；该选项明确以服务器为准。 |

| 时机 | 触发方式 |
|---|---|
| 手动 | 仅明确同步操作或命令触发传输。 |
| 实时 | 除仅下载方向外，本地变更触发同步；启动与恢复前台也检查服务器，恢复检查至少间隔十分钟。 |
| 定时 | 每 5、15、30、60、180 或 360 分钟同步，默认 30 分钟。 |

定时模式将间隔内变更合并处理；上传期间新产生的修改仍保留待同步标记。失败保留待同步修改，等待下个间隔。Timer 仅随应用进程运行，不会在退出后唤醒系统；启动或恢复前台补做过期任务，移动系统暂停进程可能导致延迟。间隔从本次尝试结束重新计算。

所有传输，包括确认配置时的首次操作与无头命令，共用串行队列；相反方向的请求不会共享错误的结果。下载等待、解压和文件暂存期间持续追踪用户修改；文件在目标卷暂存完毕、已有历史写入完成后，在同步替换文件的提交区之前再次检查本地变更代数。该边界之前出现新修改会中止导入，而不是替换本地数据库。这是进程内的提交边界，不是跨进程文件系统事务。

同步替换整包快照，**不合并**独立编辑的数据库。本地版本为零不代表收藏或历史为空；未知基线必须明确选择上传本地或下载远端。若多个最新文件使用相同数字版本，不能随意挑选其中一个下载；请在服务器保留正确文件，或明确发布本地快照。

上传使用单调递增版本和流式条件 `PUT`（`If-None-Match: *`），并发版本碰撞作为冲突处理。强 ETag 将条件下载绑定到检查过的字节内容。缺少强 ETag 的服务器仍支持明确下载或仅下载方向，但无法借此建立可信的自动双向基线；网络等待期间发生的本地新修改仍受保护。

清理保留原有同日旧快照与十份快照的意图，但候选仅限上传前已发现的旧文件，不删除碰撞版本或新发现的并发快照。删除必须提供强 ETag 和 `If-Match`，已被改动的文件保留。缺少这些校验值的服务器可能保留更多快照，需要手动维护存储空间。

## 设备本地字段与凭据边界

为保障安全与多设备独立性，以下数据属于**设备本地数据**，绝不会导出到远端同步快照（`.venera`），也不会被其他设备的下载快照覆盖：

- **WebDAV 同步凭据与连接设置**：WebDAV URL、用户名、密码。
- **当前设备同步偏好**：同步方向、时机与定时间隔。
- **本地同步状态**：待同步标记、尝试时间与绑定端点的可信基线。
- **本地存储路径**：本地漫画存储路径（`local_path`）。
- **Bangumi 本地队列**：Bangumi 待提交进度与后台失败重试队列仅在本地维护。

远端同步快照仅包含：`history.db`、`local_favorite.db`、`appdata.json`（已过滤设备敏感字段与本地路径）、`cookie.db` 以及已安装的漫画源脚本文件（`comic_source/`）。

> **WebDAV 漫画库配置同步**：
> 「WebDAV 漫画库」设置中的「同步漫画库配置」开关默认关闭。仅在两台设备均主动开启此选项时，漫画库地址与凭据才会随快照传输并在对端导入。凭据包含在远端快照中，请仅在可信的 WebDAV 服务上启用。

## 保存配置与迁移

选择实时或定时时机后，确认首次上传或下载并点击“继续”（单向设置决定操作方向）；只修改下拉选项不会传输。首次传输及持久化成功后才提交新配置；失败恢复原连接、偏好、基线和冲突状态并解除忙碌状态。若远端写入或本地数据导入已经完成，之后偏好保存失败不会撤销已完成的数据操作。手动时机只保存配置，不执行首次传输。

修改时机或间隔会重新排期；清空所有连接字段后保存即可断开同步。旧版自动同步开启迁移为实时、关闭迁移为手动，已有定时模式保留；即使新偏好已存在，也会一次性移除旧键。方向默认双向。
