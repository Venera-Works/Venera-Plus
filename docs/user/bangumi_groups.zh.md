# 漫画换源与 Bangumi 同步

English version: [bangumi_groups.en.md](bangumi_groups.en.md)

主页、本地收藏和阅读历史按实际漫画来源显示，标题和封面使用对应来源的信息。即使多个来源绑定了同一个 Bangumi 条目，也会分别显示。

## 更换漫画来源

1. 打开漫画详情页或阅读器，点击右上角「⋯ → 换源」。
2. 应用使用当前漫画名称搜索已启用且支持搜索的漫画源。可以修改关键词，处理译名或名称差异；不需要先绑定 Bangumi。
3. 点击候选结果查看其封面、简介、目录及其他信息，也可以进入某个来源的完整搜索结果继续查找。
4. 确认版本后点击「使用此来源」。查看候选、返回或取消不会替换来源。

确认后，包含原漫画的本地收藏夹会替换为新来源，保留收藏夹归属、收藏时间和排序位置；同一夹中已存在目标漫画时去重。主页及追更使用新来源，应用重启后仍然有效。换源只处理选中的原来源记录，不会因同名或绑定同一 Bangumi 条目而改动其他漫画。

从详情页换源后进入新来源详情。从阅读器换源时，有目标来源阅读记录则继续其进度，没有记录则进入详情选择章节。原来源的阅读历史和下载文件保留；章节序号和页码不会直接复制到新来源。

## 分享

详情页通过「⋯ → 分享」分享当前来源的漫画标题和链接；阅读器通过同一菜单分享当前页图片。

## 已有数据与绑定

过去合并显示的多来源收藏和历史会恢复为各自条目，不会自动删除已有记录。换源时，如果原漫画已绑定 Bangumi 且目标尚未绑定，会沿用同一条目关系，并按新来源重新自动识别章节进度；目标已有绑定时保留其绑定。

## Bangumi 同步

在“设置 → 在线服务 → Bangumi”的“网址列表”中选择服务地址，默认使用官方 `bgm.tv`，并预置 `bangumi.lat` 与 `anibt.net` 镜像。列表显示名称或主域名，各站点分别保存实际 API、图片反代和 Token 页面地址，不按子域名规则猜测。

添加自定义地址时填写实际 API 地址，可省略 `https://`；名称、图片反代和 Token 申请页面可选。图片反代留空时沿用 API 返回的图片地址，Token 页面留空时打开官方申请页面。保存后追加到列表末尾，点击该项即可切换；自定义项支持编辑和删除，删除当前使用项会恢复官方地址。所选 API 服务器会接收账号的 Access Token，请选择自己信任的服务。

每次打开列表会自动检测各 API，也可手动重新测试。延迟是当前设备按应用网络设置发起一次匿名公开接口请求的耗时；检测不会向所有地址发送 Token。验证页、超时和不兼容响应会单独标记，公开接口可用不代表账号同步已经通过验证，可使用页面中的“验证连接”检查当前账号。关闭列表会取消剩余检测。

同一 Bangumi 条目的已绑定漫画共用远端话数、卷数、评分和收藏状态。更新某一来源后，同条目的本地缓存一并更新。各来源的进度解析方式保持独立；本地章节和页码不跨来源同步。

手动回退进度会清理同一账号、同一条目、同一进度字段的冲突待上传任务，防止旧任务立即将进度推回去。后续实际阅读仍可产生新的上传进度。应用数据的跨设备同步规则见[应用数据同步](data_sync.zh.md)。
