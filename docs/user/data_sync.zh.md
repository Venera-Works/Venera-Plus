# 应用数据同步

English: [data_sync.en.md](data_sync.en.md)

入口：**设置 → 存储与同步 → 应用数据同步**。选择已连接的网盘或 WebDAV 账号和远端目录；也可以在账号选择器中添加账号后继续配置。目录大小写必须与服务端一致。未配置时，顶栏同步按钮会打开此页面；配置后顶栏可直接选择上传或下载。高级字段排除可在需要时展开。

同步使用所选远端目录中的完整快照，文件名为 `<day>-<dataVersion>-<timestamp>-<uniqueId>.venera`，默认目录为 `/VeneraPlus/`。旧 WebDAV 配置接入统一账号时会保留原 URL 下的 `VeneraPlus/` 目录。首次上传会自动创建目录。上传版本高于本机与远端已知版本，唯一后缀避免多设备并发上传互相覆盖；上传失败会还原本机版本号。成功后清理当天较低版本的快照，通常最多保留十份；同版本的并发快照会保留，可能暂时超过十份。

下载优先比较版本号，再比较日期与唯一后缀；同版本但文件不同，或旧格式文件的服务端标识变化时，仍会下载。自动下载跳过较低版本及能可靠识别为已同步的快照，旧格式文件缺少服务端标识时会重新下载。手动下载可恢复较旧版本。本版本继续读取旧的 `<day>-<dataVersion>.venera` 文件；共享目录的各设备应一并升级，旧版本无法识别新命名的快照。

快照包含设置、收藏、阅读历史、Cookie 和漫画源文件，不包含本地漫画图片、下载归档或远端漫画库内容。设置、收藏关系和阅读历史等仍按完整快照覆盖恢复，不会逐条合并并发修改。

漫画追更状态按漫画源与漫画 ID 共享持久化：首页、本地收藏、网络收藏和已跟踪漫画的详情页共用比较基准及待确认更新，切换页面或重启不会丢失。从详情页收藏或换源时使用已加载的章节、页数与日期建立基准；旧收藏缺少比较依据时，首次检查建立基准，不追溯此前的新增。新增章节、有效页数增长或更新时间前进可触发更新。首页显示源提供的更新时间，缺少有效日期时显示未知；进入阅读器不会立即清除标记，读完章节或手动标记已读后确认对应更新。

追更状态还使用每台设备独立的状态文件参与同步。上传、下载均会合并各设备发现的更新与针对具体内容版本的已读确认，不受完整快照版本号是否相同或较旧限制。某台设备确认旧章节时，另一台设备同时发现的新章节仍然保留。检查时间保留在本机。

## 同步模式

| 模式 | 行为 |
|---|---|
| 手动 | 只通过顶栏或 CLI 的上传、下载操作传输。 |
| 实时 | 本地修改后上传；启动和恢复前台检查下载，恢复检查至少间隔 10 分钟。 |
| 定时 | 每隔 5、15、30、60、180 或 360 分钟自动同步，默认 30 分钟。 |

自动同步有本地待上传修改时优先上传；没有待上传修改时才检查远端快照。阅读进度、阅读时长、历史删除及图片收藏变更在保存后标记为待上传，单纯刷新界面不会触发上传。上传失败会保留待上传标记，供下一次自动同步重试。定时器仅在应用进程运行时有效，应用关闭后不会唤醒系统。

选择实时或定时模式时，需要选择首次上传或下载。首次传输成功后才保存新配置；失败会恢复原有连接、模式、间隔和排除字段。手动模式直接保存配置。升级自旧协议时会将原有同步时机映射为手动、实时或定时模式，并优先上传本机当前数据；旧协议状态与旧云端目录不会读取、转换或删除。

## 同步边界

数据同步目标、同步模式、间隔、待上传状态、本地路径及 Bangumi 的本地重试队列保留在本机。`disableSyncFields` 中列出的设置不会写入快照。所有网盘账号及授权信息随设置同步，漫画库配置始终参与设置同步；请只在可信的存储服务上使用。

本地导入和云端下载均按完整 `.venera` 快照恢复，并在失败时还原已替换的文件。云端下载会合并本机与远端的追更状态；本地手动导入按所选备份恢复追更状态。恢复后会重新加载数据库、漫画源和相关运行时服务；仅本地手动导入会作为新的本地修改进入后续同步，云端下载不会反向触发上传。旧快照不含主页收藏夹绑定时，会解除本机旧绑定。

## 搜索历史与屏蔽规则

搜索页的历史模式按钮可切换「关键词」与「详细记录」，两份历史分别保留，删除或清空只影响当前模式。详细记录包含漫画源、筛选条件和上次实际浏览页码；同一个词在不同来源或筛选下分别记录。普通分页可直接恢复，游标分页会从头逐页定位并显示进度，期间可以取消。来源已移除时可选择替代来源；筛选选项变化时使用当前默认值并回到第一页。旧关键词继续保留，不推测原来源或页码。

「设置 → 浏览与收藏 → 关键词屏蔽」可添加或编辑漫画和评论规则。包含文字适合中文词组；独立词适合 `BL` 等短缩写，可避免命中 `black`；标签完全匹配只检查漫画标签。每条规则可设置是否区分大小写，并用「试匹配」预览结果。关键词按字面文字解释，不使用正则表达式；独立词不进行中文分词。

列表中的关键词隐藏数量可以点击查看首条命中的规则、字段和方式，并直接编辑。原因窗口只检查当前列表已加载的漫画，不显示隐藏封面，也不代表全库数量。

详细搜索历史、模式选择和规则选项随应用数据保存。旧漫画词继续区分大小写、旧评论词继续忽略大小写，升级不会自动改变旧规则。导入只含旧词表的备份时，对应词表恢复旧匹配方式；未包含的另一份词表不受影响。在高级字段排除中排除 `blockedWords` 或 `blockedCommentWords` 时，其规则选项也会一起排除。共享数据的设备应使用支持新规则的版本，旧版本无法执行新增的匹配方式。
