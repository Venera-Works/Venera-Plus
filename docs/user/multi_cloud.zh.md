# 多网盘存储

[English](multi_cloud.en.md) · [返回文档索引](../README.md)

VeneraPlus 可通过内置 OpenList 内核连接百度网盘、夸克网盘、115 网盘、123 云盘、OneDrive 和 Google Drive，也支持添加 WebDAV 账号。

内置内核由 Venera-OpenList-Core 独立构建并随应用打包；应用只使用已发布的固定内核版本，不会在设备上下载或运行 OpenList 服务。

## 添加和授权账号

在“存储与同步”的网盘账号管理页点击“添加”，先进入网盘来源列表，再点击来源打开对应账号配置页。添加百度网盘、夸克网盘、115 网盘、123 云盘和 OneDrive 时，页面只保留名称和“登录并授权”按钮；取得有效授权后自动保存并测试连接，无需手动填写令牌或 Cookie，也无需再点击保存。名称留空时使用网盘名称，重名时会在授权前提示修改。取消授权或授权失败不会保存账号，已填写的名称会保留。编辑已有账号时直接进入对应配置页，仍可修改名称及授权信息并点击“保存并测试连接”。从配置页返回可重新选择来源，从来源列表返回则取消添加。百度网盘、115 网盘、123 云盘和 OneDrive 的授权及在线令牌刷新继续使用 OpenList 官方 API；应用不会把 OpenList HTTP 服务暴露到网络。

115、123、百度和 OneDrive 的令牌自动授权使用 OpenList 提供的参数，分别对应 115 验证登录（OAuth App）、123 验证登录（OAuth官方）、百度验证登录（OAuth App）和 OneDrive 个人版本（OAuth App）。无需填写客户端 ID 或应用密钥。

夸克改用 `Quark` Cookie 驱动。点击“登录并授权”后在应用 WebView 中登录夸克官网，应用确认能读取网盘目录后，通过原生 Cookie 存储提取包括 HttpOnly 在内的完整 Cookie；新增账号随即自动保存并测试连接。已有 `QuarkOpen` 账号需重新登录，编辑保存时保留账号标识及已配置的目录，不再使用旧令牌、AppID 或 SignKey。

WebDAV 填写服务器地址、用户名和密码后保存。编辑其他已有网盘账号时可手动更新令牌或 Cookie。百度、123 和 OneDrive 需要刷新令牌，115 需要访问令牌与刷新令牌。

### Google Drive 自建 OAuth 授权

在 Google Cloud 控制台启用 Google Drive API，配置 OAuth 同意屏幕，创建“Web 应用”类型的 OAuth 客户端。将所选的回调地址完整添加到“获授权的重定向 URI”。在 VeneraPlus 新增或编辑 Google Drive 账号时，填写该客户端的 `Client ID` 和 `Client Secret`。后续刷新直接请求 Google。[Google Cloud 控制台](https://console.cloud.google.com/)

- **默认 OpenList 回调**。将“OAuth 回调地址”设置项显示的默认地址登记到 Google Cloud。在应用中保留默认值，点击“试用 WebView 通过 OpenList 授权”。此流程会将客户端凭据发送给 OpenList 换取令牌。授权成功后，应用会读取刷新令牌、保存账号并测试连接。
- **浏览器手动授权**。如果 Google 在 WebView 显示 `disallowed_useragent`，返回账号页，点击“打开 OpenList 获取刷新令牌”。在网页选择 Google Drive，填写同一组客户端凭据，完成 Google 授权后，把 `Refresh Token` 粘贴回应用，再点击“保存并测试连接”。[OpenList 官方步骤](https://doc.oplist.org/guide/drivers/google_drive)
- **自建回调**。打开“OAuth 回调地址”，填写支持 VeneraPlus 回传的完整 HTTPS 地址，确认后点击“登录并授权”。应用在系统浏览器打开 Google 授权页。完成后返回应用，应用取得刷新令牌并自动保存、测试连接。清空回调地址可恢复默认值。

#### 部署自建回调

1. 在服务器上使用 Node.js 22.1 或更新版本运行 [回调脚本](../examples/google_drive_callback.mjs)。

   ```sh
   node google_drive_callback.mjs
   ```

2. 将自己的 HTTPS 域名上的 `/googleui/callback` 反向代理到 `http://127.0.0.1:8787`，转发该路径的 GET（含查询参数）和 POST 请求，并关闭该路径的缓存和访问日志。脚本使用单进程的内存保存会话，有效期为五分钟。
3. 将完整地址（例如 `https://drive.example.com/googleui/callback`）同时填入 Google Cloud 控制台和应用。回调服务只传递一次性授权码，应用直接向 Google 交换令牌。使用普通自建 OpenList APIPages 时，可在其网页授权后手动填写刷新令牌。

已有刷新令牌时，可以直接填写并保存。也可继续使用 [Google OAuth Playground](https://developers.google.com/oauthplayground/) 获取令牌，将 `https://developers.google.com/oauthplayground` 登记为重定向 URI，并启用 **Use your own OAuth credentials**。`https://www.googleapis.com/auth/drive.readonly` 可用于浏览和阅读，写回元数据、同步或备份需要 `https://www.googleapis.com/auth/drive`。

原先使用 OpenList 公共凭据的用户应编辑原账号，并用相同的 Google 账号重新授权。原账号及其漫画库、同步和备份目录的关联会保留。外部 OAuth 应用处于 **Testing** 状态时，需先添加测试用户，Drive 刷新令牌会在 7 天后过期。

## 配置用途和漫画目录

“设置 → 存储与同步”按用途集中展示网盘账号、在线漫画库、应用数据同步和漫画归档备份，并显示当前账号、目录及同步状态。账号只需添加一次，各用途共用授权；选择账号时可直接添加新账号，完成后继续当前配置。首次成功连接账号后，也可直接选择用途。

“设置 → 来源与服务 → 内容来源”统一管理网站源和远程漫画库，并按类型分组。点击“添加”后选择来源类型：网站源可从仓库安装或通过链接、文件导入；远程漫画库直接选择网盘账号和漫画目录，也可在配置途中新增账号。“存储与同步”中的“在线漫画库”以及发现、搜索中的来源管理入口均打开同一页面。

“在线漫画库”可为每个漫画库选择一个账号和一个或多个识别目录。目录会合并展示；相同完整远端路径的漫画只显示一次，不同目录下的同名漫画会分别显示。应用数据同步和漫画归档备份各自选择一个账号和一个目录：前者同步设置、收藏、阅读记录等应用数据，后者备份和恢复 CBZ 漫画文件。

选择目录时，点击文件夹名称进入，点击行尾选框勾选；“当前文件夹”一行可选择当前目录，包括根目录和空文件夹。跨目录浏览会保留勾选，底部显示已选数量，点击右下角“完成”返回配置页；返回键取消本次选择。漫画库可多选，同步和备份只允许选一个目录。

## 刷新、缓存和限流

打开在线漫画库时会先显示已缓存或新发现的作品，封面、作者和标签等信息在后台逐步补全。打开详情或选择分卷时，再读取所需的章节与文件内容。点击漫画库的刷新按钮会重新请求远端目录，并在发现或补全信息后更新列表。外部新增、删除或移动漫画后，可用此操作刷新目录；列表开始显示不代表整次扫描已经完成。

新建的 115 漫画库默认关闭“自动更新漫画库”，其他来源默认开启，已有漫画库保留原设置。开启后可选择每 15 分钟、每小时、每 6 小时或每天更新，默认每 6 小时；只在应用运行期间检查。首次打开尚无索引的漫画库仍会建立索引，即使自动更新已关闭。此间隔独立于应用数据同步的定时间隔。

自动扫描会复用有效的本地目录缓存，115 的缓存有效期为 1 小时，其他来源为 10 分钟；缓存会跨重启保留，手动刷新始终重新请求远端目录。多个识别目录分别扫描：成功目录更新索引，失败目录保留原索引并记录错误，扫描期间已经发现的新作品仍可能显示。发生目录读取错误时，不会把失败目录当成空目录清除已有作品。

检测到限流后，同账号的目录、直链、元数据写回、普通图片和阅读分段请求会暂停，已有本地内容仍可使用。优先遵守服务端给出的重试时间，未提供时默认冷却 15 分钟；冷却状态保存在本机，手动刷新和重启不会提前恢复这些请求。启动时的待处理元数据写回也遵守重试时间。

## 在线阅读格式

在线漫画库支持图片目录、远端 ZIP/CBZ、图片型 EPUB 和 PDF。同一作品的分卷文件可聚合展示，明确的版本目录与重复卷使用阅读分组切换；不同格式的非重复分卷可连续阅读。各卷及封面按需解析和缓存，连续阅读与预加载不会越过版本边界。独立 ZIP/CBZ 保留章节目录与分组，EPUB 按 spine 顺序阅读并区分章节与页码导航，PDF 按原始页码渲染并支持书签分章。布局示例和元数据规则见[漫画导入与在线阅读](import_comic.zh.md#zipcbz图片型-epub-与-pdf-云端按需阅读)。

云端文件按需阅读要求实际文件服务支持 HTTP Range。服务器忽略 Range、返回整包或无效分段时会明确失败，不会自动下载整个文件；通过网盘直链、代理或重定向访问时同样适用。ZIP/CBZ 支持 Store/Deflate 的 ZIP/ZIP64，不支持加密、分卷或其他压缩方式。7z/CB7 仍需先下载后本地导入，或将漫画图片解压到远端目录。

## 跨设备配置和旧数据

旧 WebDAV 同步和归档配置会自动接入统一账号，保留原同步目录和归档目录。本地漫画位置、缓存与下载线程归入“本地存储与下载”，手动数据导入和导出归入“应用数据导入与导出”。

所有已保存的网盘账号及授权信息都会随应用数据快照同步，包括尚未用于漫画库的账号和 Google Drive 客户端密钥。123 云盘的访问令牌、刷新令牌、绝对过期时间与授权更新时间整组同步，同一账号采用较新的授权，旧快照不会覆盖较新的本机令牌。新设备和重启后优先使用已有访问令牌，到期或接口明确拒绝后才刷新；旧授权没有过期时间时先尝试访问，不在导入时重新计算有效期。其他网盘恢复快照时仍优先保留本机有效授权；数据同步目标始终保留在本机。漫画备份配置是否同步由“同步备份配置”选项决定。

123 云盘刷新遇到临时网络或服务异常后可再次重试；明确的 `invalid_grant` 会保留原始错误并标记授权失效，需要重新登录或同步更新的授权。若网盘在刷新后废弃旧刷新令牌，尚未同步新授权的设备仍可能需要重新授权。

网盘账号名称必须唯一，比较时忽略首尾空格和英文大小写。同一账号在不同设备上请使用相同名称，不同账号请使用不同名称；同步时，同名且网盘类型相同的账号会自动合并，并更新漫画库、同步和备份目录的账号引用，保留漫画库标识与收藏关联。同名但类型不同的账号会保留，并自动添加名称后缀以区分。修改账号名称仍保留内部账号标识。

快照包含账号授权，数据范围与本机保留项以[应用数据同步](data_sync.zh.md#同步边界)为准。目录索引、图片缓存和限流冷却状态保留在本机。

## 平台范围

macOS 应用仍支持 macOS 12；受内核运行时限制，OpenList 六种网盘仅在 macOS 13 及以上可用。在 macOS 12 上，WebDAV 和本地功能仍可使用。
