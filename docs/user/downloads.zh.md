# 下载与缺页补下载

图片下载任务菜单中的「继续下载其余可用图片」默认关闭。开启后，重试耗尽的连接错误、404／410 缺图和不支持的图片数据会记录为缺页，其余页面继续下载；认证、证书、取消和本地写入错误仍停止任务。

含缺页的任务保留在下载队列，不登记为完整本地漫画。任务信息显示缺失章节和页码，重新开始时先补齐缺页，已完成图片不重复下载；选项和缺页位置随队列保存，重开应用后保持暂停。

Android 的用户下载会启动前台服务，显示进度通知并支持通知栏暂停。网络中断采用有上限的退避重试，网络恢复和返回前台可提前唤醒等待；不会恢复用户主动暂停的任务。服务与当前应用进程共同存活，系统强制停止和厂商省电限制仍会中断下载。
