# 下载与缺页补下载

图片下载任务菜单中的「继续下载其余可用图片」默认关闭。可在「设置 → App → 本地存储与下载」配置新任务的默认选项，已有任务和重启恢复的任务保留各自设置。开启后，重试耗尽的连接错误、404／410 缺图和不支持的图片数据会记录为缺页，其余页面继续下载；认证、证书、取消和本地写入错误仍停止任务。

含缺页的任务转为「待补页」，不阻塞后续队列。本地漫画标记缺页数量，已下载页面可以先阅读，未下载的位置显示占位并保留原页码。可在任务菜单或本地漫画菜单选择「补下载缺页」，成功页面不重复下载；选项和缺页位置跨重启保留，重开应用后保持暂停。

从队列移除待补页任务会保留已有本地页面，之后仍可从本地漫画菜单重新创建补页任务。若来源的页面列表已变化，需要重新下载对应章节。补齐前不允许导出或归档该漫画，避免产生不完整备份。

Android 的用户下载会启动前台服务，显示进度通知并支持通知栏暂停。网络中断采用有上限的退避重试，网络恢复和返回前台可提前唤醒等待；不会恢复用户主动暂停的任务。服务与当前应用进程共同存活，系统强制停止和厂商省电限制仍会中断下载。
