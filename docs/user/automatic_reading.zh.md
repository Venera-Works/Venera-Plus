# 自动阅读与阅读信息

在阅读器菜单中启动自动阅读，或将长按动作设为开始／停止自动阅读。分页模式按间隔翻页，连续和瀑布流支持平滑或分步滚动。

默认等待图片成功加载。可在阅读设置中开启「自动阅读时跳过不可用图片」：失败图片按正常阅读节奏跳过；加载中的图片在等待时间耗尽后继续。等待时间默认为 10 秒，可设为 1–60 秒，只计算没有操作阻塞的前台时间。触摸、长按、菜单和后台会暂停推进；章节加载错误仍需重试。

连续和瀑布流在手势结束后可以保持放大继续滚动，速度按屏幕距离计算，末页尾部读完后才停止或跨章。分页模式主动放大时暂停自动翻页。

Android 和 iOS 默认在自动阅读期间保持屏幕常亮，可在阅读设置关闭；停止自动阅读、切后台或退出时恢复系统休眠。图片等待、常亮和原始像素尺寸显示沿用全局／设备／单本设置。

「浏览与收藏 → 显示详细阅读进度」为历史记录和已开启阅读记录角标的漫画卡片增加章节与页码总数。章节和分组名称随正常阅读保存；旧记录缺失名称或总数时保留序号，不额外联网补齐。分组章节的总数按所在分组计算。

## 阅读诊断

阅读器右上角菜单中的「阅读诊断」可手动开始最多 45 秒的采集，浏览页面、快速回看后重新打开诊断即可停止、预览和复制报告。切后台、切换阅读模式或退出时停止，退出阅读器后清除报告；默认关闭且不上传。

报告仅包含匿名图片编号、数值耗时、缓存状态与基本阅读配置，不包含漫画、标题、路径、网址、账号、脚本或错误正文。读取、处理、解码和显示的等待时间用于区分慢在哪个阶段，不能直接当作 CPU 耗时；界面帧样本也不等于整段实测帧率。采样开始前或预加载已完成的工作可能没有阶段记录。
